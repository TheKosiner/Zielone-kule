# Zielone Kule – panel produkcji i biznesu

Osobisty panel do kul ogrodowych z hipertufy z żywym mchem: partie i harmonogram, kalendarz, dziennik, wydatki, sprzedaż z ewidencją, instrukcje i biznesplan. Działa w przeglądarce, bez serwera.

> Projekt powstaje etapami. Opis architektury i modelu danych: [docs/ARCHITEKTURA.md](docs/ARCHITEKTURA.md).

## Uruchomienie

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # testy jednostkowe
npm run build    # wersja produkcyjna w dist/
```
